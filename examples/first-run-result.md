# 社区书店：三个选题角度

本次全部书店材料都是合成教学示例，不代表真实书店或真实人物。暂按“普通读者，愿意看社区小店日常和小事怎么处理”来找角度；这里只交选题，不写全文。

可用材料：预约书与待归还书原来混放；店员小林把书架分成两区，并在预约书上写取书日期；试行一周记录一次取错书；没有改动前错拿次数。最后一句按“缺少改动前的数据”理解，不能当作改动前零次。

## 1. 首推：社区书店里，小林给两种书分了家

**中心问题／观看体验：** 看一次具体整理：两种用途不同的书原来混放，小林怎样把书架改成两区，再把取书日期写出来。

**为什么值得看：** 动作小而具体，观众能跟着一处书架看明白发生了什么，无须先知道这家店。

**已有材料／缺口：** 有原来的混放、分区和写日期这三个节点，足以讲一次简短的过程记录。没有分区位置、标识样式和真实画面；不能把未知操作补成教程，也不能承诺分区已经减少错拿。

**下一步：** 若继续制作，先按现有材料画一张“两区＋日期”的示意图并标明合成演示；如要扩成现实案例，再取得现场画面和具体操作记录。

## 2. 分完书架，一周记录了一次取错书：这说明有效了吗？

**中心问题／观看体验：** 围绕这一次记录，弄清“看见一个数字”和“知道改善了多少”差在哪里。

**为什么值得看：** 很多人会遇到类似的小改动：做完后有一份记录，却不一定知道效果如何。书店这件小事可以把这个判断说具体。

**已有材料／缺口：** 有试行一周一次的记录，也明确缺少改动前的数据。现阶段足以讲“还不能证明减少”，不足以讲有效、无效或改善比例；取书总次数、漏记情况、原来错拿的口径也都未知。

**下一步：** 先整理同口径的改动前后记录和取书总次数；没有历史记录，就保留这个缺口，另设后续观察，不能倒填一个改动前数字。

## 3. 换成来取书的人：书架分了区，能看懂该拿哪本吗？

**中心问题／观看体验：** 从顾客实际取书的动作进入，观察他如何辨认区域、理解取书日期，以及在哪里还需要店员帮助。

**为什么值得看：** 这次关心的是使用过程是否清楚，和店员怎样整理、统计上是否改善是三个不同问题。

**已有材料／缺口：** 分区和写日期提供了观察对象，但材料里没有任何顾客的动作、反馈或困惑。这是待补材料的探索方向，问号不代表已经证明顾客看得懂或看不懂。

**下一步：** 若以后做现实观察，在得到参与者同意后记录一次取书过程：看了哪里、何时询问、是否拿对。问“你是怎么找到这本书的”，不预设“这样是不是更方便”。本次不执行、不编结果。

## 取舍

优先做第 1 个：现有材料可以兑现一个短小的过程。第 2 个适合解释证据边界；第 3 个需要补顾客使用过程，当前不能做成已经验证的体验结论。

## 这次用了什么

- 可感知的实用价值 → 把“社区书店”收窄成“分两区、写日期”两个看得见的动作，形成第 1 个角度。
- 换视角与立场 → 第 3 个从整理者换成取书者，问题随之变成“怎么辨认”，并把顾客行为保留为待观察项。
- 材料与判断分开 → 第 2 个围绕缺失的改动前数据提问，没有把一次记录写成改善成果；这是基于本次材料做的编辑判断。
