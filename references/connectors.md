# 14种关联词：改变关系，而非替换词语

第14章前8种：`sources/community/zsxq-22255158555485441`；第15章后6种：`sources/community/zsxq-14422825588882812`。选中后读完整相应章节。表格保留方法差异，例子是本技能的合成示意，不是用户经历。

| 关系/原句式 | 需要的材料与操作 | 合成示意 | 必须检查 |
|---|---|---|---|
| 归因更正：不是A而是B | 先确认常见归因，再展示支持替代解释的证据 | 卡住的是哪一步，而非笼统怪工具 | 不能仅靠一个反例证实唯一原因 |
| 路径取舍：与其A不如B | 同一目标下比较两种行动、成本与适用条件 | 同一小时修旧稿还是再写一篇 | 不是在所有条件下B都好 |
| 价值底线：宁可A也不B | 真实愿意承担的代价及不愿接受的事 | 接受慢一点，也要保留某种生活安排 | 不替用户编造决绝态度 |
| 原因解释：之所以A是因为B | 从现象追问机制、过程和证据 | 为什么这次交接反复返工 | 相关现象不能直接成为因果 |
| 补另一面：虽然A但是B | 同一事物两面都成立 | 做成了原型，但实际使用还卡在哪 | 不为了转折否认已有成果 |
| 关键前提：只有A才B | 找到有依据的必要条件 | 某个流程在什么条件下才能继续 | “只有”强于“有帮助”，不得偷换 |
| 循环关系：越A越B | 有变化过程或重复观察 | 整理越细，维护是否越累 | 明确样本；不臆造单调规律 |
| 重定义：与其说A不如说B | 同一现象怎样更准确理解 | 这次记录更像什么体验 | 不把新比喻冒充事实机制 |
| 场景并置：一边A一边B | 两种同时发生的动作 | 一边开会一边哄娃 | 同时发生与先后发生不同 |
| 前后变化：原来A现在B | 真实前后状态及变化节点 | 原来怎样记录，现在怎样找回 | 条件和时间范围要清楚 |
| 程度反差：连A都B | 一个值得解释的特殊样本 | 连熟悉流程的人也在哪步停住 | 特殊样本不能代表全体 |
| 行动推导：既然A那就B | 已成立的前提及有逻辑的行动 | 既然当前只能周末拍，如何安排一次尝试 | 不把未知前提当已证实 |
| 两难选择：要么A要么B | 两种确实互斥的选择及代价 | 两个时间冲突的机会怎么取舍 | 还有第三条路时不能制造假两难 |
| 预期落差：明明A却B | 合理期待和实际结果不同 | 明明按步骤做了，哪一步仍不成立 | 不能先假定有人故意阻碍 |

每条候选写出它带来的新问题和需要的材料。若14个句式只是在表达同一个结论，合并表达版本；不要报成14个不同选题。
