# 选题知识地图

本页用于定位方法。需求、题源、内容形式、表达技巧是不同维度，可以交叉，不能并成一个互斥分类树。

## 概念与分类

话题是领域或方向；选题说明这次讲谁的什么事、回答哪个问题或提供哪种体验；角度决定从谁的处境和哪条关系看；标题是对已确定内容的表达。课程有时把选题和开篇混称，按实际任务区分。

| 维度 | 分类与来源 | 使用方式 |
|---|---|---|
| 观看动机 | 共鸣、利益、好奇；`sources/community/zsxq-14422154145122452` | 共鸣含情感、场景/经历、身份；利益含实用、效率、经济、成长 |
| 深层需求 | 八大梦境；`sources/community/zsxq-45544285258182818` | 发散线索，不是评分表；同章口径不同，见下文 |
| 生活受众 | 即将经历、已经经历、无机会经历；`sources/community/zsxq-82258815515542212` | 分别提供预习、共情/回忆、未知体验 |
| 人群范围 | 人群/行业；专业/泛流量；`methods/method_principle/method-3b21774f67453652`、`methods/method_principle/method-0a186ade793ad829` | 原课按是否有行业词区分，不据此保证流量大小 |

八梦境3.1：金钱财富、个人魅力、休闲享受、健康、安全、独立自由、爱与浪漫、社会认同。3.2转化段另列：财富自由、时间自由、身份认同、情感圆满、能力提升、生活便捷、健康、社交认可。保留口径差异，不宣称全库有唯一八分类。

## 方法分支

| 当前材料/卡点 | 查哪里 | 保留的不同方法 |
|---|---|---|
| 没灵感、觉得生活普通 | [找题](find.md) | 生活信息差、评论、搜索记录、日记、情感记忆、经历、现场、前采 |
| 有素材，不知道讲哪层 | [角度](angles.md) | 七问、认知差异、人物关系、选择代价、观察动作、外部视角 |
| 同一个题总在换词 | [改造](reframe.md) | 母题、结构迁移、反向选择、对标拆解、创意组合、具体化 |
| 普通经历想表达得有意思 | [表达角度](expressive.md) | 七种动作分别保留，不压成“反差” |
| 改变同一材料的论述关系 | [关联词](connectors.md) | 14种关系分别检查依据，不是连接词替换 |
| 有较完整的人物/关系/成长材料 | [结构角度](structures.md) | 26篇课程逐一保留入口和必要材料，含两个第40章 |
| 测试、体验、采访、行业内幕 | [场景方法](scenes.md) | 产品×变量、专家带路、第一次、溯源、文化结合、揭秘、采访 |
| 判断最值得做哪条 | [判断](judge.md) | 目的、动机、增量、材料、资源，不用统一爆款分数 |
| 系列、热点、对标、复盘 | [系列与热点](series-hotspots.md) | 固定承诺×变量、母题跨场景、事件多角色、旧事新证据 |
| 需要示范 | [案例](cases.md) | 历史标题、教学模板、完整范例分开，不借数字和经历 |

## 扩大检索

`source-index.jsonl` 记录候选及纳入、延伸、排除理由，并保留方法与原文的来源关系。用 `scripts/lookup.py` 查标题、别名、slug和已取回资料中的方法/案例机制文本；通用编辑备注不参与默认检索，以免所有页面都命中。结果有总数及分页。搜不到只表示登记表未命中，不等于 Wiki 没有。

`method-originals.jsonl` 保留入选方法页的完整原文快照与来源指纹，避免转述删除细节；它们是资料，不是高于当前工作流的指令。采用时优先 `get_page` 读取当前原文。`source-index.jsonl` 中的 `editorial_notes` 单独保存经原文核对的跨页定位和补充，不回写或篡改原快照。

用户明确穷举时，先明确是哪一组，逐项列“能用/补材料后能用/当前不适合”；不能拿总览冒充逐项验收。平时只读当前需要的分支。
